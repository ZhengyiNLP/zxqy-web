## 二、开发环境启动

### 2.1 后端启动

```powershell
cd E:\桌面\zxqy-web\backend
```

## 三、生产部署

### 3.1 前端构建

```powershell
cd E:\桌面\zxqy-web\frontend
npm run build
```

构建产物在 `frontend/dist/` 目录。

### 3.2 部署方式一：FastAPI 托管静态文件（单机部署）

1. 将 `frontend/dist/` 内容复制到 `backend/static/`
2. 启动后端服务：

```powershell
cd E:\桌面\zxqy-web\backend
uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

3. 访问 http://服务器IP:8000/ 即门户首页
4. 访问 http://服务器IP:8000/login 即管理后台

### 3.3 部署方式二：Nginx 反向代理（推荐生产）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 上传文件代理
    location /uploads/ {
        proxy_pass http://127.0.0.1:8000;
    }
}
```

启动后端：
```powershell
cd /path/to/backend
uv run uvicorn main:app --host 127.0.0.1 --port 8000
```

### 3.4 切换 MySQL 数据库

1. 设置环境变量：
```
DATABASE_URL=mysql+pymysql://用户名:密码@localhost:3306/zxqy_web
```

2. 重启后端，首次启动自动建表+种子数据

## 四、部署验证

部署后执行以下验证：

1. 访问首页，确认页面正常加载
2. 访问 /login，用 admin/admin123 登录管理后台
3. 在管理后台发布一条新闻，确认前台首页能看到
4. 在前台提交一条留言，确认后台留言管理能看到
5. 访问 /docs 确认 API 文档可访问（生产环境可关闭）

## 五、安全注意事项

- 首次部署后立即修改 admin 默认密码
- 生产环境设置 `ALLOWED_ORIGINS` 环境变量限制 CORS
- 生产环境设置 `JWT_SECRET` 环境变量（固定密钥）
- 定期备份 `backend/data/app.db`（SQLite）或 MySQL 数据库
- 上传目录 `backend/uploads/` 需设置合理的文件权限
