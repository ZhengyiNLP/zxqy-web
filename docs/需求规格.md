## 一、心智模型对齐（1.0）

### 参考系统
无特定参考，采用通用中小企业门户标准模型。

### 核心实体清单（8个）

| 序号 | 实体 | 描述 |
|------|------|------|
| 1 | 栏目分类 | 网站内容分类树，组织新闻、产品等内容的归属 |
| 2 | 新闻文章 | 企业动态、行业资讯、通知公告等信息内容 |
| 3 | 产品展示 | 企业产品/服务的展示信息（图片、描述、规格等） |
| 4 | 单页内容 | 关于我们、企业文化、联系方式等固定页面内容 |

| 7 | 轮播图 | 首页轮播广告图/Banner，可配置跳转链接 |
| 8 | 友情链接 | 合作伙伴或关联网站的链接管理 |

### 实体关系
- 管理员 → 管理所有内容实体（新闻、产品、单页、轮播图、友情链接、留言）
- 栏目分类 → 新闻/产品多对一归属（一条新闻/产品属于一个栏目分类）
- 单页内容 → 独立于栏目分类，按页面标识直接展示
- 留言咨询 → 访客提交，管理员查看处理

## 二、项目概述

本项目是一个面向中小企业的通用门户网站模板，采用前后端分离架构。前台提供企业信息展示（首页、新闻动态、产品展示、关于我们、联系方式、留言咨询），后台提供内容管理（新闻/产品/单页/轮播图/友情链接/留言的增删改查）。网站支持响应式布局，适配桌面端和移动端。

目标用户：需要对外展示企业形象的中小企业，可复用此模板快速搭建门户。

## 三、用户角色定义

| 角色 | 说明 | 主要场景 |
|------|------|---------|
| 访客 | 普通网站浏览者，无需注册登录 | 浏览首页、查看新闻、查看产品、了解企业信息、提交留言咨询 |
| 管理员 | 后台管理系统操作人员 | 管理新闻、产品、单页内容、轮播图、友情链接、查看处理留言 |

## 四、访客端需求（Web 门户）

**核心目标：** 向访客展示企业形象、产品服务、新闻动态，并提供在线咨询入口

### 1. 首页模块

#### 功能点 1.1: 首页轮播图展示
- **用户故事**：作为访客，我想要在首页看到轮播广告图，以便快速了解企业重点推介内容
- **详细描述**：
  - 首页顶部展示后台配置的轮播图，自动轮播，支持手动切换
  - 每张轮播图可配置标题、图片、跳转链接
  - 移动端自适应展示
- **状态**：已明确

#### 功能点 1.2: 企业简介展示
- **用户故事**：作为访客，我想要在首页看到企业简介，以便快速了解企业基本情况
- **详细描述**：
  - 首页展示企业简介摘要（从"关于我们"单页内容提取）
  - 提供"了解更多"链接跳转到关于我们详情页
- **状态**：已明确

#### 功能点 1.3: 最新动态展示
- **用户故事**：作为访客，我想要在首页看到最新发布的新闻动态，以便及时了解企业最新消息
- **详细描述**：
  - 首页展示最新发布的 N 条新闻（可配置展示数量，默认6条）
  - 每条显示标题、发布时间、摘要
  - 点击跳转到新闻详情页
- **状态**：已明确

#### 功能点 1.4: 产品精选展示
- **用户故事**：作为访客，我想要在首页看到精选产品展示，以便快速了解企业核心产品
- **详细描述**：
  - 首页展示标记为"推荐"的产品（可配置展示数量，默认4-8个）
  - 每个产品显示名称、缩略图、简短描述
  - 点击跳转到产品详情页
- **状态**：已明确

#### 功能点 1.5: 友情链接展示
- **用户故事**：作为访客，我想要在页脚看到友情链接，以便访问相关合作网站
- **详细描述**：
  - 页脚区域展示后台配置的友情链接
  - 新窗口打开链接
- **状态**：已明确

### 2. 新闻动态模块

#### 功能点 2.1: 新闻列表页
- **用户故事**：作为访客，我想要按栏目浏览新闻列表，以便查看感兴趣类别的新闻

- **关键交互**：选择栏目 → 加载对应新闻列表 → 翻页浏览
- **状态**：已明确

#### 功能点 2.2: 新闻详情页
- **用户故事**：作为访客，我想要查看新闻详情内容，以便了解完整信息
- **详细描述**：

  - 正文支持富文本（图片、段落、列表等）
  - 底部展示上一篇/下一篇导航
  - 移动端自适应排版
- **状态**：已明确

### 3. 产品展示模块

### 4. 单页内容模块

#### 功能点 4.1: 关于我们页
- **用户故事**：作为访客，我想要查看企业详细介绍，以便了解企业背景和文化

## 五、管理员端需求（后台管理系统）

**核心目标：** 管理网站所有内容，包括新闻、产品、单页、轮播图、友情链接和留言

### 1. 系统登录模块

#### 功能点 1.1: 管理员登录
- **用户故事**：作为管理员，我想要通过账号密码登录后台，以便管理网站内容
- **详细描述**：
  - 用户名 + 密码登录
  - JWT Token 认证
  - 登录后进入管理后台首页（仪表盘）
- **状态**：已明确

#### 功能点 1.2: 仪表盘概览
- **用户故事**：作为管理员，我想要在后台首页看到网站数据概览，以便了解网站运营情况
- **详细描述**：
  - 显示新闻总数、产品总数、未读留言数、轮播图数量
  - 显示最近留言列表（最新5条）
- **状态**：已明确

### 2. 栏目分类管理

#### 功能点 2.1: 栏目分类 CRUD
- **用户故事**：作为管理员，我想要管理新闻和产品的栏目分类，以便组织网站内容结构
- **详细描述**：
  - 新增栏目分类（名称、类型[新闻/产品]、排序值、启用状态）
  - 编辑栏目分类
  - 删除栏目分类（有关联内容时不允许删除或需确认）
  - 列表展示所有分类，支持排序
- **状态**：已明确

### 3. 新闻管理

#### 功能点 3.1: 新闻 CRUD
- **用户故事**：作为管理员，我想要发布和管理新闻文章，以便更新网站动态内容
- **详细描述**：
  - 新增新闻：标题、栏目分类、摘要、正文（富文本编辑器）、封面图、发布状态（草稿/发布）、发布时间
  - 编辑新闻
  - 删除新闻
  - 新闻列表：支持按栏目筛选、按标题搜索、按时间排序、分页
- **状态**：已明确

#### 功能点 3.2: 新闻状态管理
- **用户故事**：作为管理员，我想要控制新闻的发布状态，以便管理草稿和已发布内容
- **详细描述**：
  - 草稿 → 发布：前台可见
  - 发布 → 草稿/下架：前台不可见
  - 支持定时发布（可选，待澄清）
- **状态**：待澄清（定时发布是否需要）

### 4. 产品管理

#### 功能点 4.1: 产品 CRUD
- **用户故事**：作为管理员，我想要管理产品信息，以便展示企业产品服务
- **详细描述**：
  - 新增产品：名称、产品分类、简短描述、详细介绍（富文本）、主图、多图（图集）、产品参数（键值对，可选）、排序值、是否推荐、上架状态
  - 编辑产品
  - 删除产品
  - 产品列表：支持按分类筛选、按名称搜索、分页
- **状态**：已明确

### 5. 单页内容管理

#### 功能点 5.1: 单页内容管理
- **用户故事**：作为管理员，我想要编辑关于我们、企业文化、联系我们等固定页面内容，以便更新企业信息
- **详细描述**：
  - 页面列表：关于我们、企业文化、联系我们（等预设页面）
  - 编辑页面内容（富文本编辑器）
  - 联系我们页可单独编辑结构化字段（地址、电话、邮箱、办公时间）
  - 保存后前台立即更新
- **状态**：已明确

### 6. 轮播图管理

#### 功能点 6.1: 轮播图 CRUD
- **用户故事**：作为管理员，我想要管理首页轮播图，以便控制首页展示内容

## 六、非功能性需求

### 6.1 性能要求
- 页面首屏加载 < 3s（正常网络环境）
- 接口响应 < 500ms
- 图片懒加载，减少首屏带宽

### 6.2 兼容性
- 桌面端：Chrome 90+、Edge 90+、Firefox 88+、Safari 14+
- 移动端：iOS Safari 14+、Chrome for Android，响应式布局适配主流手机尺寸

### 6.3 安全要求
- 后台管理需 JWT 认证，未登录不可访问管理接口
- 留言表单需防重复提交、基础 XSS 防护
- 管理员密码 bcrypt 哈希存储
- 图片上传需限制文件类型和大小

### 6.4 可用性
- 初期部署级可用，支持单机部署
- 数据库默认 SQLite（零配置），可平滑切换 MySQL

### 6.5 SEO 基础
- 语义化 HTML 标签
- 页面 title、description 可配置
- 静态化友好的 URL 结构（可选，待澄清）
