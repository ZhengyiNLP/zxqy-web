## 二、变更内容

### 1. 关于我们 404 修复（A线）
- 根因：About.vue 用 `defineProps<{ pageKey: string }>()` 接收页面标识，但路由未配置 `props` 传参，导致实际请求 `/api/v1/portal/pages/undefined`，后端返回 4041，前端显示"页面不存在"
- 修复：About.vue 改为组件内固定 `PAGE_KEY = 'about'`（与 Culture.vue 硬编码模式统一），与路由传参解耦

### 2. Banner 清新化 v2（B线）
- 渐变基底：#a7d4f7→#57a7ee 三段渐变升级为 #d9ecfb→#aad6f6→#74baf1→#4fa8e9 四段斜向渐变，层次更丰富
- 光效：去掉 `filter: blur` 小光斑（显脏），改为大范围弥散光雾（两层 radial-gradient ellipse，右上 55% 白雾 + 左下 34% 柔光），天空感
- 轮播指示器：Element Plus 默认圆点改为简约短横线样式（未激活 26px 半透明白细线，激活 40px 白色实线）
- banner-item 与 hero-placeholder 底色统一

### 3. 首页移除企业简介板块（B线）
- 删除 Home.vue 的 about-section（企业简介 + 特性卡片 + 了解更多按钮）
- 首页结构变为：banner → 新闻动态 → 产品展示
- 企业介绍内容集中在"关于我们"页面，消除重复
- 同步清理 aboutSummary/aboutFeatures 相关代码与样式

### 4. GitHub 部署准备

- .gitignore 调整：演示数据纳入版本控制——backend/uploads/ 演示图片（8 张）、backend/data/app.db（演示数据库）随仓库部署；排除 .jwt_secret（安全）
