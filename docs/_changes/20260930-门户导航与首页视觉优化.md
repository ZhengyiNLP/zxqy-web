## 二、问题分析

### A线 bug：导航菜单项粘连（根因修正）
- **最初判断**：`.desktop-menu :deep(.el-menu-item)` 设置 `margin: 0` 且未显式声明 `padding`，覆盖了默认内边距。
- **真根因（DOM 排查后修正）**：模板项目自带自研 Base 组件体系（BaseButton/BaseCard 等），**从未全局注册 Element Plus**，vite 也未配置 unplugin 按需导入插件。所有 `el-xxx` 组件（导航菜单、轮播、表格、表单、分页等）被 Vue 当作**未知自定义元素**渲染（如 `<EL-MENU-ITEM>`，无任何组件样式与交互），这才是菜单文字粘连的真实原因，且影响范围是**全部页面的所有 Element Plus 组件**，不仅是导航。
- **修复**：`main.ts` 全局注册 Element Plus（`app.use(ElementPlus)` + 引入 `element-plus/dist/index.css`），同时显式声明菜单项 `padding: 0 26px`。与模板自研 Base 组件互不冲突，原有 Login 等页面不受影响。

### B线设计调整：视觉风格对标柳钢集团官网
参考截图的标杆特征：
- 导航采用"左品牌-中栏目-右功能"经典布局，等距宽松分布
- 导航为透明通栏设计，白色文字悬浮叠加在 banner 之上（无底色、与 banner 融合）
- banner 通栏大图 + 渐变基底 + 柔化层叠波浪，视觉开阔大气
- 滚动时导航切换为实色背景保持可用性（置顶悬浮）

当前实现的差距：
- 导航为白色实底，与 banner 割裂，不够大气
- banner 无图时仅纯色渐变，缺乏层次
- 板块间距/命名一致性不足（首页"产品精选" vs 导航/页脚"产品展示"）
