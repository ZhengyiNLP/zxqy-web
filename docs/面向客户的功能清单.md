中小企业门户网站功能清单

一：访客端（Web门户）

1.1 首页展示
1.1.1 首页轮播图
功能详细描述：1.首页顶部展示后台配置的轮播广告图，自动播放并支持手动切换；2.每张图可配置标题和跳转链接；3.移动端自适应展示。

1.1.2 企业简介展示
功能详细描述：1.首页展示企业简介摘要；2.提供"了解更多"链接跳转到关于我们详情页。

1.1.3 最新动态
功能详细描述：1.首页展示最新发布的新闻动态；2.每条显示标题、发布时间和摘要；3.点击可跳转到新闻详情。

1.1.4 产品精选
功能详细描述：1.首页展示推荐产品；2.每个产品显示名称、缩略图和简短描述；3.点击可跳转到产品详情。

1.1.5 友情链接
功能详细描述：1.页脚展示合作伙伴或相关网站链接；2.点击在新窗口打开。


1.2 新闻动态
1.2.1 新闻列表
功能详细描述：1.按栏目分类浏览新闻列表；2.支持分页浏览；3.每条新闻显示标题、发布时间、摘要和缩略图。

1.2.2 新闻详情
功能详细描述：1.展示新闻完整内容，支持富文本图文排版；2.底部提供上一篇和下一篇导航；3.显示发布时间和浏览量。


1.3 产品展示
1.3.1 产品列表
功能详细描述：1.按分类浏览产品列表；2.支持分页；3.每个产品显示名称、缩略图和简短描述。

1.3.2 产品详情
功能详细描述：1.展示产品详细介绍，支持富文本图文排版；2.支持多图展示，主图加图集可放大查看；3.显示产品参数和规格信息。


1.4 企业信息
1.4.1 关于我们
功能详细描述：1.展示企业详细介绍页面；2.支持图文混排的富文本内容。

1.4.2 企业文化
功能详细描述：1.展示企业文化价值观内容；2.支持图文混排的富文本内容。

1.4.3 联系我们
功能详细描述：1.展示企业地址、电话、邮箱和办公时间等联系信息；2.提供在线留言入口。


1.5 留言咨询
1.5.1 提交留言
功能详细描述：1.访客填写姓名、联系电话、邮箱和留言内容；2.提交后提示成功；3.基础信息格式校验。


二：管理员端（后台管理系统）

2.1 系统登录
2.1.1 管理员登录
功能详细描述：1.通过用户名和密码登录后台管理系统；2.登录后进入管理仪表盘。

2.1.2 仪表盘概览
功能详细描述：1.显示新闻总数、产品总数、未读留言数等数据统计；2.展示最近收到的留言列表。


2.2 栏目分类管理
2.2.1 分类管理
功能详细描述：1.新增、编辑、删除栏目分类；2.分类区分新闻类型和产品类型；3.支持排序和启用禁用控制。


2.3 新闻管理
2.3.1 新闻发布与编辑
功能详细描述：1.新增新闻包括标题、栏目、摘要、富文本正文和封面图；2.支持草稿和发布两种状态；3.编辑和删除已有新闻。

2.3.2 新闻列表管理
功能详细描述：1.按栏目筛选、按标题搜索、按时间排序；2.支持分页浏览；3.控制新闻上下架状态。


2.4 产品管理
2.4.1 产品发布与编辑
功能详细描述：1.新增产品包括名称、分类、描述、主图和多图画集；2.可设置产品参数和推荐标记；3.编辑和删除已有产品。

2.4.2 产品列表管理
功能详细描述：1.按分类筛选和按名称搜索；2.支持分页浏览；3.控制产品上下架状态。


2.5 单页内容管理
2.5.1 页面内容编辑
功能详细描述：1.编辑关于我们、企业文化、联系我们等固定页面；2.使用富文本编辑器更新内容；3.联系我们可单独编辑结构化联系信息。


2.6 轮播图管理
2.6.1 轮播图管理
功能详细描述：1.新增、编辑、删除轮播图；2.可配置标题、图片和跳转链接；3.支持排序和启用禁用控制。


2.7 友情链接管理
2.7.1 友情链接管理
功能详细描述：1.新增、编辑、删除友情链接；2.可配置名称和网址；3.支持排序和启用禁用控制。


2.8 留言管理
2.8.1 留言查看与处理
功能详细描述：1.查看访客提交的留言详情；2.标记留言为已读；3.按处理状态筛选；4.删除无效留言。


2.9 系统设置
2.9.1 网站基础信息
功能详细描述：1.设置网站名称、Logo和备案号；2.配置首页展示条数等参数；3.保存后全站生效。

2.9.2 修改密码
功能详细描述：1.输入旧密码验证后设置新密码；2.保障账号安全。
